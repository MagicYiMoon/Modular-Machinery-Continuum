# 可视化编辑导入模板

此窗口自 MMC 1.4.0 提供。外部适配器及转换范围见[外部配方导入](EXTERNAL_RECIPE_ADAPTERS_ZH.md)。

MMC 1.4.0 采用网络协议 33，两端需要一起更新。追加的气动或魔法资源需求仍须安装对应联动模组，并在机器结构中配置相应仓室；仅在模板里填写用量不会自动创建供能／储存部件。未安装依赖时，对应可视化入口会隐藏。

1. 先通过工具、指令或 JSON 创建机器，以有编辑权限的账号执行 `/modularmachinery gui`。
2. 选中机器，点击“导入模板”。左栏列出属于当前机器的模板；可选择已有模板，或点击“+ 新导入模板”。切换模板会放弃未保存的当前草稿。
3. 新建时填写文件 ID，保存到 `config/modularmachinery/recipes/<ID>.adapter.json`；已有模板的文件名与所属机器保持原样，不通过此窗口改名。
4. 搜索并选择服务器已注册的适配器。未安装对应联动模组的适配器不会出现在列表中。`minecraft:furnace` 可用于导入原版熔炉配方。
5. “修改器”调整源配方的时间、资源数量或概率；“追加需求”进入独立草稿窗口，支持普通配方的需求选择和背包物品入口。点击“完成追加需求”返回模板，此时尚未写文件。
6. 点击“保存并生成”，等待服务器确认。窗口显示上次实际加载数量，悬停查看导入／跳过报告；左下方状态被截断时，悬停可阅读完整原因。

修改器应用于适配器所转换的源配方，追加需求按填写值附加，不会再次套用这些修改器。空导入也可以保存，例如源配方当前没有匹配项；窗口会报告实际数量为 0，不能把“已保存”理解为一定生成了配方。

适配器生成的配方保持只读。需要修改导入策略时请回到模板；普通配方复制不会把生成结果转换为可编辑源文件。模板属于多台机器时，新增接口分组和智能接口引用必须对所有所属机器有效。

保存期间会锁定操作；服务器拒绝保存后保留当前草稿，可查看原因、修正后重试。已有文件、旧窗口、权限不足、过期数据和磁盘上的外部修改均会被拒绝。若写入后的模板加载失败，会撤销本次文件修改并重新加载；若文件随后被外部编辑，则保留外部内容并提示检查源文件。关闭窗口不自动保存草稿。

单次模板提交最多 32767 字符、32 个修改器、128 个追加需求；严格 JSON 校验拒绝重复键、尾随内容、超过 48 层或 8192 个节点的数据。生成后的编辑器同步内容超过上限时，也会撤销本次模板保存。过大的模板或面板未支持的高级修改器应继续通过源文件维护，勿依靠文本截断来保存。
