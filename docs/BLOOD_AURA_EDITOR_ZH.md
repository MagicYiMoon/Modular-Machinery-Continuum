# LP、恶魔意志与自然灵气可视化编辑

MMC 1.3.0 新增，协议 32。管理员执行 `/modularmachinery gui`，选中机器与普通 JSON 配方，点击输入／输出框 `+` →“魔法资源”。该入口同时包含之前的 Botania 魔力和 Embers 余烬，按服务器实际依赖显示资源选项。新机器仍通过选区工具、指令或 JSON 创建。

| 资源 | 用量与方向 | 处理方式 | 条件／批量 |
| --- | --- | --- | --- |
| 生命源质 LP（Blood Magic） | 0～2147483647 整数，输入／输出 | 单次：开工扣除／完工添加；逐 tick：LP/t | 使用已绑定血球的接口与所有者灵魂网络；可设置随批量或整批一份 |
| 恶魔意志（Blood Magic） | 有限非负小数，输入／输出，可用科学计数法 | 仅单次 | 区块意志；输入消耗后至少保留 min，输出产出后不得超过 max；整批只算一份，无批量策略按钮 |
| 自然灵气（Nature’s Aura） | 0～2147483647 原生整数单位，输入／输出 | 仅单次 | 输入消耗后至少保留 min-aura，输出产出后不得超过 max-aura；阈值允许负整数，可设置用量的批量策略 |

先选择资源，再填写用量。LP 可单击“单次／逐 tick”切换；意志与灵气显示类型按钮和当前方向的阈值输入框。类型按钮单击依次切换，悬停可查看完整 ID 和说明。灵气类型来自服务器实际注册列表，包括第三方注册的类型，服务器保存时再次校验。不要为主世界机器误选其他维度的灵气类型。

意志类型为 `raw`（原始）、`corrosive`（腐蚀）、`destructive`（破坏）、`vengeful`（复仇）、`steadfast`（坚韧）。意志的 min/max 分别用于输入／输出，不要求 min≤max。灵气的两个阈值同样分别生效，不作为统一范围校验；允许 -2147483648～2147483647，阈值本身不会随批量倍率放大。

点击已有需求可修改本资源用量、类型和当前方向的条件，不能原位变更资源家族或输入／输出方向。用量编辑保留另一方向的阈值、显式 perTick:false、接口分组、触发、批量标记和未知作者字段。没有概率选项；带 chance 等高级定义请检查源文件。保存后的接口分组和批量按钮继续沿用既有操作。

非法值禁用保存，等待服务器确认时禁止继续修改；保存失败保留草稿，取消未提交修改不会写文件，改变 GUI 缩放保留草稿。脚本／适配器生成来源仍只读。未安装对应资源模组时隐藏其选项，服务器也拒绝相关写入。客户端与服务器需要使用同一版 JAR。

当前版本复用已有原生资源运行时，没有将资源转换为 FE，也没有改写工厂的线程或批量规则。服务端／客户端验证范围见 [功能范围与测试说明](../TESTING.md)，实现记录见[功能范围与测试说明](../TESTING.md)。
