# 定向能源输出端口

MMC 1.3.0 新增。无需额外模组；两端须使用包含本功能的相同构建。普通能源输出仓仍按原来的六面相邻输出规则运行。

## 用途与放置

方块 ID：`modularmachinery:blockenergyoutputport`。它作为机器的 FE 输出部件，将配方产能暂存在自身缓冲，并沿正前方直线输送到有 FE 接收能力的方块；可以跨过空隙，不需要在中间放线缆。

放置时正面朝向玩家，支持上下左右前后六个方向。红石块面表示未连接，观察者面表示已连接，亮红石灯面表示近期正在输出；这些是当前复用原版资源的状态标识，并非 gugu 的原纹理。空手右击查看缓存和已连接目标的世界坐标。端口只主动查询前方，外部 FE 只允许从正面抽取；不接受外部灌入，不是转发其他发电机输入的中继器。

默认扫描 **3 格**，含距离 1 和 3 的位置。沿射线遇到第一个方块实体就停止：如果它不接收 FE，后方即使有能源仓也不会连接。不透明、可遮挡的实心方块同样挡住射线；空气与玻璃等非遮挡方块可以穿过。现代实现以 `BlockState.canOcclude()` 作为旧版不透明立方体规则的对应判断。

目标从朝向端口的一面取 FE 能力，无该面能力时再尝试无方向能力。目标每 **10 tick** 更新一次，近邻变化、朝向／距离配置变化会提前刷新。远处障碍物发生变化后，最长约 10 tick 才重新识别，这是缓存刷新规则。目标替换、能力失效或沿线区块卸载后停止供能；不加载区块、不跨维度。

## 缓冲与限额

端口使用固定 **2,147,483,647 FE** 缓冲，主动输送与外部 FE 抽取共享 **214,748,364 FE/t** 上限，符合容量 10% 的传输规则。它没有八档等级，不读取普通 FE 仓的分档配置。实际送入量仍受对方容量和接收速度限制。

没有目标或目标已满时保留能量；缓冲也满时，配方按普通 FE 输出空间规则暂停。重新连接后继续输送。缓冲随区块保存，但挖掉端口时不保留缓存，放置新端口为空。没有提供 Flux 专用长整数能力，以免绕过正面与每 tick 额度；此端口与外部设备的连接使用标准 FE。

这是对旧 gugu 端口的明确调整：旧实现没有稳定的持久缓冲，未输出部分可能被清空，并包含整数溢出和极大数退化为 1 的分支。这里保留定向／距离／阻挡玩法，使用可持久化、有边界的缓冲，不复现丢电行为。

## 配置

游戏实例 `config/modularmachinery-common.toml`：

```toml
[general]
energy-output-port-range = 3
```

允许 **1～256**，默认 3；沿用 gugu 原配置的默认值与范围。修改已有文件中的键即可，不要重复新增 `[general]` 小节。服务端决定扫描距离；两端建议分发相同配置。

工作台配方：上方玻璃、中央任意等级的 MMC 能源输出仓、左右红石、下方铁锭。合成不继承材料能源仓的等级或能量，建议使用空仓。整合包可以替换这个配方。

## 机器与配方

显式加入机器结构，不会自动替换普通能源仓。例如放在控制器上方，并标记输出选择器：

```json
{"x":0,"y":1,"z":0,"elements":"modularmachinery:blockenergyoutputport","selector-tag":"power_out"}
```

使用已有 FE 需求，无需新资源类型：

```json
{"type":"modularmachinery:energy","io-type":"output","energyPerTick":250,"selector-tag":"power_out"}
```

普通机器、工厂与批量倍率共用现有配方执行；例如两倍加工时每个推进 tick 产生 500 FE。同一种配方最多占一个工厂线程的规则保持。裸方块 ID 不限定朝向，摆放时自行把正面对准接收方；结构工具与木棍自动装配可使用这个部件，但自动装配后的方向仍须按目标检查。

服务端已实际验证方向、距离、阻挡、原生 FE 接收与普通／工厂配方，结果见 [功能范围与测试说明](../TESTING.md)，来源与实现见[功能范围与测试说明](../TESTING.md)。新增现代束流与浮动 FE/t 读数，客户端测试范围见 TESTING。


## 束流与 FE/t 读数

连接到距离大于 1 的有效接收方时显示细蓝束流；实际传输时动态流动，并显示近 10 tick 平均的真实 FE/t。数值包含主动推送和被接收方抽取的实际接收量，不统计模拟调用或未接收的能量。接收端满时会归零，断连后清除；紧贴接收方不显示跨方块束流，沿用旧附属的距离规则。

束流支持六方向并参与场景深度遮挡。仅同步变化后的距离和平均流量，客户端不重新射线扫描，不逐 tick 发送静止状态；这些临时视觉数值不写入区块磁盘存档。使用独立生成的纹理和现代批量顶点接口，未复制旧 gugu 素材。外观为现代近似，浮字面向摄像机，并非逐像素复刻旧 TESR。
