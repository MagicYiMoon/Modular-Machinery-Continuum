# 通量网络联动（MMC 1.2.0）

适用于 Minecraft 1.20.1 / Forge。已适配 Flux Networks **7.2.1.15**，需在客户端和服务端另行安装；MMC 的发行 JAR 不包含通量网络本体。未安装时 MMC 可正常独立运行。

## 如何连接

- **给机器供能**：把通量节点（Flux Point）紧贴机器的能源输入仓，在节点中选择有电源的网络。
- **把机器发电送入网络**：把通量插头（Flux Plug）紧贴能源输出仓，在插头中选择目标网络。
- 能源仓六个面均可连接。输入仓不能被外部抽走能量，输出仓不能被外部充电。
- 插头、节点的网络选择、权限、优先级、传输限额仍由 Flux Networks 管理。
- 机器结构与配方继续使用原来的 FE 输入／输出需求，不需要新增结构部件或修改配方类型。

完整路径示例：

```text
发电机器 → 能源输出仓 → 通量插头
                           ↓ 无线网络
用电机器 ← 能源输入仓 ← 通量节点
```

## 容量与传输速度

本联动提供 Flux Networks 原生 `IFNEnergyStorage` 能量接口，与标准 Forge Energy 共用同一个能源仓库存。两种连接方式不会分别存储能量，也不增加额外 NBT 格式。

普通能源仓仍采用现有 FE 容量和传输配置，容量最高为 **2,147,483,647 FE**。通量网络关闭传输限制不会突破能源仓自身的限制，也不会改变默认容量。长整型请求会先限制到安全范围，负数请求不进行传输。

输入和输出仓都使用 `config/modularmachinery-common.toml` 中的等级配置：

```toml
[energyhatch.size]
ultimate = 2147483647

[energyhatch.limit]
ultimate = 131072
```

`capacity` 是库存容量，`transfer` 是单次接口传输上限；输出仓主动向相邻方块输送时，每 tick 的所有面共用这一额度。外部设备多次调用的实际速率还受外部模组调度影响。更改等级参数后建议重启游戏／服务器，使已加载能源仓重新创建。

## 开关与回退

默认启用，可在同一文件中设置：

```toml
[general]
enable-fluxnetworks-integration = true
```

设置为 `false` 关闭 MMC 的通量网络专用接口和输出优先通道，**不会关闭标准 FE 连接**。Flux Networks 自身仍可能通过 FE 与能源仓连接。不要用此开关作为禁止通量网络供电的权限设置。

## 与新星工程的区别

此功能是普通能源仓的 Flux Networks 联动，不注册 `novaeng_core:dreamenergyport` 梦之能量端口，也不附送梦之能量核心、其动画、配方或超大整数储能系统。

## 开发运行

编译依赖固定为 CurseMaven `curse.maven:flux-networks-248020:5234697`。用 `-PwithFluxIntegration` 把正式外部模组加入开发运行环境；它始终不进入 Jar-in-Jar。

测试代码会验证实际 FN 连接器、所有能源仓等级与朝向、模拟与实际传输、数值边界、存档、配置回退、能力失效，以及真实插头／网络／节点之间的能量守恒。隔离服务端运行方法见 [VERIFY.md](../VERIFY.md)。
