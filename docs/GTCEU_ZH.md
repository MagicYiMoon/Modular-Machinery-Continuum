# GTCEu Modern 普通总线、流体仓与 EU 能量仓联动

MMC 1.3.0 新增。 核对版本是 Forge 1.20.1 的 GTCEu Modern **7.5.3**，上游将该版本标记为 beta；当前可选依赖声明接受 `7.5.3 ≤ 版本 < 7.6`，尚未验证其他版本。没有安装 GT 时 MMC 仍可独立运行。

## 安装与结构配置

使用包含本次源码改动的 MMC，并在两端安装相同的官方 GTCEu 版本。普通玩家使用官方完整包（含所需前置），开发用 slim 包与依赖拆分只用于本项目 Gradle 环境。下载与依赖来源见[依赖说明](../libs/optional/README.md)。

在机器结构中明确允许需要的 GT 方块，或使用选区工具选入这些方块后导出机器。不会自动把结构中要求的 MMC 输入／输出方块替换成任意 GT 方块；仍需满足你写的结构条件。识别出的 GT 普通仓室参与原有 MMC 配方，配方格式不变，普通控制器和工厂控制器都可使用，批量倍率继续生效。

| GT 部件 | MMC 用途 | 常见方块 ID 示例 |
| --- | --- | --- |
| 普通物品输入总线 | 配方取料 | `gtceu:lv_input_bus` |
| 普通物品输出总线 | 配方产物存入 | `gtceu:lv_output_bus` |
| 普通流体输入仓 | 配方抽取流体 | `gtceu:lv_input_hatch` |
| 普通流体输出仓 | 配方产出流体 | `gtceu:lv_output_hatch` |
| 普通 4x／9x 流体仓 | 使用全部液槽 | 在 GT 中选取相应电压等级的多重输入／输出仓 |
| 普通 EU 能量输入／输出仓 | 消耗／产出配方能量 | `gtceu:lv_energy_input_hatch`／`gtceu:lv_energy_output_hatch` |
| 普通 4A／16A 能量仓 | 同上，使用仓内 EU 缓冲 | `gtceu:ev_energy_input_hatch_4a`／`gtceu:ev_energy_output_hatch_16a` |
| 64A 变电仓 | 同上 | `gtceu:ev_substation_input_hatch_64a`／`gtceu:ev_substation_output_hatch_64a` |

方向以 GT 部件的内部配方 IO 为准，不从朝向猜测。选择器标签仍按 MMC 结构位置过滤。GT 自己朝外的输入／输出限制不影响 MMC 对已匹配部件的内部取料／产出；实际管道连接和自动搬运仍受 GT 自己的设置控制。

## EU 配方能量

配方仍填写 FE/t，固定按源 MMCE 的 **1 EU = 4 FE** 换算。例如 32 FE/t 消耗 8 EU/t；3 FE/t 也可以正常使用，仓室会记录不足一 EU 的转换余数，不会每 tick 向下取整而漏扣能量。倍率不跟随 GT 的 FE 转换器配置。

每个仓室单独保存 0～3 FE 余数，区块卸载／存档重读后保留；输出累计到 4 FE 才写入一 EU。整数 EU 缓冲满时仍可暂存最多 3 FE。直接拆除后放置新仓不会自动继承余数，本联动没有新增掉落物储能保留功能。模拟查询不会扣能。

GT 对外仍使用自己的 EU 网络、朝向、电压／安培与过压规则，本联动没有给 GT 方块增加对外 FE 能力。MMC 内部配方沿用源版的内部容器读写语义，不额外按网络电压限速，不引入 GT 超频；普通 MMC FE 仓的容量 10% 传输规则也不套用到 GT。长整数 EU 换算后的显示可能达到 FE 整数上限，但配方预检仍检查实际可接收／提取的能量。

## 保留的规则与范围

- 保留普通总线的物品过滤、流体锁定、液槽分配、容量、模拟调用及内容变更通知；不复制一份虚拟库存。
- 可编程电路槽没有作为普通消耗物品暴露。GT 电路号、distinct 总线分组、涂色分组、GT 配方超频等不转译成 MMC 条件，MMC 继续使用自己的配方和线程规则。
- 不改 GT 的控制器归属或附着状态。MMC 结构匹配并记录位置，但不会把它伪装成 GT 多方块控制器；若多个机器共享库存，它们消费的是同一份资源。
- 暂只接入 GT 的普通 `ItemBusPartMachine`、`FluidHatchPartMachine`、`EnergyHatchPartMachine` 具体类型（含普通 1x／4x／9x 流体仓和 2A／4A／16A／64A 能量仓）。ME、蒸汽、储液库、泵、创造／无限仓和其他特殊子类尚未接入，也不会仅因实现 Forge 能力就自动接入。
- **激光仓尚未实现。** 普通 EU 能量仓、MMC 能源仓和既有 FE／Flux 接口可按各自规则使用。
- 未新增 GT 方块特殊自动放置代理或 GT 配方导入器；当前版本只涉及已放置普通仓室的配方 IO。
