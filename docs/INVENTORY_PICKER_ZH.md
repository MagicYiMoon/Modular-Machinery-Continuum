# 从背包选择配方物品

此功能自 MMC 1.4.0 提供，入口为管理员可视化编辑器。

在 `/modularmachinery gui` 中选中机器和可编辑配方，点击输入或输出区域的 `+`，选择“物品”，再点击物品选择窗口右上方的“背包”。点击列表中的物品后，可以继续调整数量、概率，最后保存需求。

- 列表显示玩家主背包、快捷栏、盔甲栏和副手中的非空物品；同一物品的不同物品堆分别显示，保留各自的名称与 NBT。
- 支持物品名称／ID、`@模组ID`、`#物品标签` 搜索，多个词用空格分隔。
- 默认带入物品堆数量，普通物品数量范围为 1～64；选择物品不会消耗、移动或给予背包物品。
- “带入 NBT”开关决定是否复制物品数据。输入字符串会转为字面匹配条件，输出则使用实际输出数据。关闭后只带入物品类型和数量；替换原物品时会清除该候选项原有的 NBT 和显示 NBT。
- 候选输入组、随机输出组、催化剂的“添加物品”和“重新选择”也可以切换至背包；耐久需求只列出可损耗物品。

某些数据不能通过现有配方 NBT 模式无损表示，例如 NBT 数组；此时会提示原因并保留选择窗口，可关闭“带入 NBT”后重试。候选项未设置独立 NBT 时，仍按配方规则继承整组默认 NBT。背包物品是编辑素材，不会自动成为容器内物品或流体需求。

保存仍需服务器编辑权限。模板中的追加需求先保存在模板草稿中，只有保存模板后才写入配置并重新生成配方。
