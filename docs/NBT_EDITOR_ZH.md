# 物品／流体 NBT 编辑与预览

MMC 1.3.0 新增；客户端和服务器需要使用同一版本。入口为 `/modularmachinery gui`。

## 操作

选择已保存的配方和需求，点击配方栏下方的 **NBT 数据**。已有 `nbt` 或 `nbt-display` 的受支持需求，点击该需求也会直接打开 NBT 窗口。无 NBT 的普通需求仍先打开原数量窗口；取消后点击 NBT 数据即可。

当前版本支持直接物品／物品标签输入、物品耐久需求、直接流体及逐 tick 流体需求的 NBT。新需求需先保存；候选输入组、随机输出组、催化剂、燃料、气体及第三方需求不在此入口范围内。脚本和适配器生成配方仍只读。这里不改变数量、概率、方向、对象、触发、批量或接口分组。

1.4.0 新增候选组与催化剂内部 NBT 编辑：打开候选输入组、随机输出组或催化剂，选中具体候选项后点击“候选 NBT”，或点击“默认 NBT”编辑整组默认数据。“应用”只修改当前需求草稿，返回后仍需保存需求；模板中的需求则需返回并保存模板。取消 NBT 窗口不会应用该次修改。未填写独立数据的候选项按既有规则继承整组默认值，清除独立数据会恢复继承；显示数据与实际匹配／产出数据分别设置。

窗口分为两个页签：

| 页签 | 作用 |
| --- | --- |
| 输入的“匹配条件 · nbt” | 限制允许消耗的物品／流体；不会向输入资源写数据 |
| 输出的“实际输出 · nbt” | 指定产物真正携带的数据 |
| “显示数据” | 独立 `nbt-display`，用于配方展示，不参与实际匹配或产出 |

每个页签可以选择 JSON 对象或既有 MMCE 模式文本，在多行框内编辑。“预览”显示解析后的数据摘要；悬停摘要可读换行提示；提示最多显示 12 行，超长内容会截取并引导返回编辑框查看原文。它不生成测试产物，也不是物品图形模型预览。格式切换只切换解释方式，**不会自动转换内容**。

点击“清除”或将已编辑字段留空会移除该字段。明确填写 `{}` 则保存为空复合对象；两者不同。移除 `nbt-display` 后，展示回退到 `nbt`，没有两者时使用资源默认外观。未编辑的页签保留原对象／字符串表示，包括原本的空模式字符串。

“保存”等待服务器写入、重载和确认后关闭窗口；失败保留草稿并提示原因。“取消”或 Esc 放弃这次修改。切换页签及 GUI 缩放保留当前草稿。磁盘源文件被外部修改后会拒绝覆盖，应先重载并重新打开。

## 输入条件示例

在 JSON 对象格式中输入：

```json
{
  "quality": ">=3",
  "name": "Coal|Carbon"
}
```

这是子集匹配：允许输入有其他键；`quality` 必须通过数字比较，`name` 必须完整匹配正则 `Coal|Carbon`，不区分大小写。仅包含 Carbon 的一部分文字并不满足完整匹配，若需包含关系可写 `.*Carbon.*`。无效正则不能保存。

对应模式文本格式：

```text
{quality:>=3,name:"Coal|Carbon"}
```

JSON 中键和字符串必须使用双引号；不接受重复键、尾随内容、null 根或非对象根。数字比较支持既有比较符和类型后缀，例如 `>=2.0d`。引号只保护内容，**不会把输入字符串正则变成字面相等比较**；需匹配正则特殊字符时应正确转义。

## 输出和显示分离

在输出需求的实际输出页填写模式文本：

```text
{quality:7}
```

在显示数据页填写：

```text
{quality:99}
```

机器产物的 `quality` 为 7，展示使用 99。输出中的数字比较符按原有规则去掉，例如 `>=7` 物化为 7；字符串产出为原字符串，不会随机生成满足正则的文字。不要把用于展示的名称、等级等误写成实际输出条件。

流体使用同样规则，数量单位仍是原需求的 mB 或 mB/t；NBT 窗口不改变单次／逐 tick 类型。物品耐久需求的 NBT 用于选择可扣耐久的工具，不会修改耐久消耗量。

## 限制

这是多行文本编辑与解析预览，尚无树状标签编辑、从手持物品抓取 NBT 或候选组内部标签编辑。模式文本沿用 MMCE 语法，**不是完整原版 SNBT**；不要假定原版类型数组等所有语法都可直接粘贴。

每字段最多 8192 字符；过深／过多节点会拒绝，最大深度为 48，JSON 最多 2048 个节点，模式文本有对应分隔符数量保护。列表成员必须能物化为同一种 NBT 类型。超过界面长度的旧配置拒绝打开，不会截断后覆盖；请先编辑源文件。

数量／概率与对象重新选择的原窗口仍拒绝带 NBT 的高级需求；当前版本提供独立 NBT 入口，不会简化或擦除这些条件。候选组和催化剂的 NBT 请继续编辑 JSON／脚本。机器创建方式、工厂线程和机器／并行控制器倍率不变。验证证据与覆盖边界见 [功能范围与测试说明](../TESTING.md)，后续见[功能范围与测试说明](../TESTING.md)。
