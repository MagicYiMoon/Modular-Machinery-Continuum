# EC 基础结构演示（MMC 2.0.0）

这里是 C4／C6／C9 的最小结构定义，演示物理部件归属和内存等级，**不是新星工程原结构**。不要与同名正式机器定义同时安装。将 `machinery` 内的三份 JSON 复制到测试实例的 `config/modularmachinery/machinery`，重载机器定义后放置对应的固定 EC 主机；没有添加默认生存配方。

控制器朝北时，其右侧一格为传输总线，上下各一格为晶阵驱动器，后方为 ME 通讯接口；线程核心、超线程核心和并行核心沿右方继续排列。以蓝图／结构预览显示的实际朝向为准。通用 MMC 控制器不是 EC CPU 宿主，应使用 `extendable_calculator_subsystem_l4`／`_l6`／`_l9`。

主手持 EC 闪存晶阵潜行右键驱动器插入，主手空手潜行右键取出。漏斗与物品管道操作整枚晶阵。EC 闪存晶阵与 ES 存储矩阵不同，不能互换。

| 晶阵 | 实际内存 bytes | 可用主机 |
| --- | ---: | --- |
| `ecalculator_cell_64m` | 65,536,000 | C4／C6／C9 |
| `ecalculator_cell_1024m` | 1,048,576,000 | C6／C9 |
| `ecalculator_cell_16384m` | 16,777,216,000 | C9 |

高档晶阵可以放进驱动器，主机等级不足时不会计入内存。普通核心 L4／L6／L9 提供 1／2／4 普通槽；超线程核心提供 0＋2／0＋4／1＋8 普通＋超线程槽；并行核心提供 256／2048／16384 共享额度。核心的安装限制由机器结构决定，没有额外主机等级门槛。

右键主机打开任务界面，查看内存、核心占用和任务。中部核心区、右下任务区分别用滚轮或箭头翻页；悬停查看完整数值。红色 × 在五秒内点击两次确认取消；网络装不下材料时显示“退料中”，内存与槽位暂不释放。缺少 AE2 或任务数据无法读取时，共享占用显示 `?`。“超线程内存”包含该类任务的全部预留 bytes；“并行额度”不是实际每秒产量。

安装 AE2 后，将通讯接口连入有供电和可用频道的 ME 网络；成型且装有受支持晶阵与可用线程核心时，公开一个显示剩余内存的空闲 EC CPU。使用 AE 原有终端下单，材料和样板由该 ME 网络提供，不能直接在 EC 内添加 MMC 配方。普通槽优先，普通槽满后使用额外占用约 10% 内存的超线程槽；已满或剩余内存低于总量约 10% 时撤下空闲 CPU，已有任务继续执行。

安装 The One Probe 后，探测成型主机可查看内存、线程、并行额度和实际统计；探测线程核心可查看绑定状态及最多四个任务，更多任务到主机界面查看。断电时保留暂停任务，无法读取时显示未知；扩展探测模式显示完整大数。EC 通讯接口沿用源版 1 AE/t 的节点待机耗能，由 AE 网格供电。

世界方块已接入源版在线／运行灯态、成型大型外观和动态尾部隐藏，菜单分页栏旁显示 CPU 更新平均耗时，悬停该数字或任务可查看实际样板推送均值；按最近最多 100 次 CPU 更新计算，一个样板产出多个物品仍只计一次推送，统计不写入存档。当前最小演示沿用第一阶段的直线部件摆放，只演示功能绑定，不适合展示大型外观：主机成型会覆盖并隐藏周围 17 格，应按源模型为主机预留 3×3×2 空间。制作正式机器时，建议将工作部件放在后方，从局部 z=2 开始，并使用名为 `workers` 的动态段，让尾部随实际长度定位；规则见适配说明。实际拆除节点、结构失效或网格分裂可能触发 AE2 的任务取消；恢复供电与网络不保证所有外部生产机器都能续接。更多说明见[NECO 指南](../../docs/NECO_GUIDE_ZH.md)。
