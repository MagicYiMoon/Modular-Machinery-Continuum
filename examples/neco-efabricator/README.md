# EF 基础制造演示（MMC 2.0.0）

此目录提供 F4／F6／F9 的最小机器定义。把所需 JSON 复制到测试实例 `config/modularmachinery/machinery/`，使用现有机器重载指令重新读取。专用 EF 方块固定注册；本示例不增加动态注册项。请只在备份或可丢弃世界试用。

使用对应的 `modularmachinery:extendable_fabricator_subsystem_l4`、`_l6` 或 `_l9` 主机。先按 JSON 在局部 x=-1..1、y=-1..1、z=0..1 填十七块结构外壳，中心 `(0,0,0)` 留给主机。工作核心放 `(0,0,2)`，对应档位并行核心放其上方 `(0,1,2)`，样板总线放 `(0,0,3)`，ME 通讯接口放 `(0,0,4)`。坐标随主机朝向旋转，正面朝北时局部 +x 是世界东、+z 是世界南。空手右键主机打开监控，查看是否成型及实际队列、能量和冷却数据。

将 ME 通讯接口连接到有电且有频道的 AE 网络，空手右键样板总线放入合成样板（也支持 Forge 物品管道），即可在 ME 终端下单。当前支持普通、未冷却超频及下文的主动冷却制造；普通加工、切石和锻造样板只保存，不发布。普通模式每 20 tick 执行一次工作周期，核心有 500,000 AE 缓存，基础每次合成消耗 100 AE；回网另外支付 AE 传输用电。

网络拒收时，产物和容器返还物保存在主机缓存并暂停新增制造；空间恢复后继续回网。工作核心、样板总线及主机正常采掘后，各自的私有数据随唯一方块物品保存，重新放置恢复。不要直接替换或删除仍有工作的方块。主机监控、样板总线及检索界面已接入；主机成型时换源版大型模型并隐藏十七块外壳，工作核心显示离线／待机／保留工作三态灯。灯态跟随真实队列，不保证当前有电或正在消耗材料。主机右上角的检索按钮可按材料或产物名称查找样板，点击结果取出编码样板，鼠标携带编码样板时点击结果区放入。

## 主动冷却

在对应机器 JSON 的 `parts` 中增加以下两项，重载结构定义后在相应位置放置流体舱室：

```json
{"x":1,"y":0,"z":3,"elements":"modularmachinery:blockfluidinputhatch"},
{"x":-1,"y":0,"z":3,"elements":"modularmachinery:blockfluidoutputhatch"}
```

在 `config/modularmachinery-common.toml` 的 `[neco.efabricator]` 中设置 `coolants`。每项为 `输入流体ID|输入mB|输出流体ID|输出mB|冷却单位`；例如源规则的水变蒸汽应使用 `minecraft:water|1|实际蒸汽流体ID|1|15`，将“实际蒸汽流体ID”换成已安装模组的真实注册 ID。没有对应流体时默认条目不启用，不会自动注册蒸汽。无热流体输出可写 `输入流体ID|1|-|0|240`，这种转换不需要输出舱室。不要把示例占位文字直接填入配置。

空手右键主机，在左侧点击超频或主动冷却按钮切换模式，悬停可查看说明。冷却模式每次合成消耗 100 AE 与 5 冷却单位，缺液或热流体输出堵塞时等待；存量冷却单位仍可用。普通模式也会预充冷却缓存，采用源版规则。完整转换与加速规则见[适配记录](../../docs/NECO_GUIDE_ZH.md)。

示例只演示功能绑定，不复刻源整合包结构或生存配方。大型主机固定替换上述十七格的模型，即使自定义定义不同也会隐藏这些位置；不要在该范围放需要看见的部件。旧的最小演示布局不再适用，应按新版 JSON 调整。规则及当前边界见 [EF 适配记录](../../docs/NECO_GUIDE_ZH.md)。

安装 The One Probe 后可探测工作核心的绑定状态、缓存 AE、队列占用及当前／排队产物。在线仅代表结构绑定；缺少 AE2 与未知保存格式会另行提示。与源版一样，不给其他 EF 部件附加此工作核心面板。
