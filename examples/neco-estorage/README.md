# ES 结构演示（MMC 2.0.0）

这三份 JSON 是 MMC 为验证宿主绑定编写的最小演示，不是新星工程原结构；仅用于 ES 矩阵、ME 通道与内部能源单元的开发验证。源版控制器依赖整合包提供同名机器定义，因此没有自动安装默认结构或生存配方。

需要时将 `machinery/` 内 JSON 复制到测试实例的 `config/modularmachinery/machinery/` 后重载机器定义。不要覆盖已有同名机器。分别使用 `modularmachinery:extendable_digital_storage_subsystem_l4`、`_l6`、`_l9` 对应的 ES 控制器，不使用通用／自动生成的普通控制器。

控制器朝北时，控制器本身是原点；按本项目结构坐标转换，在 x=1、y=0、z=0 放专用矩阵驱动器，x=2、y=0、z=0 放 ES 外壳，x=0、y=0、z=1 放 ES 存储 ME 通道，x=-1、y=0、z=0 放对应 L4／L6／L9 的能源单元。其他朝向跟随控制器旋转。右键控制器打开 ES 统计面板，查看成型／ME 状态、驱动器数量、容量／类型占用和 AE 储能；左侧悬停标签切换统计，也支持点击；提示查看完整数值。默认七项图表，安装 AppMek 后增加气体 bytes／类型两项。分类 bytes 占比按全部有效矩阵总容量计算，耗能比例为待机耗能／当前内部储能；按 Shift 查看储能绝对值。右侧矩阵列每页六行，滚轮或底部箭头翻页。演示不要求蓝图。实际包可以用这些固定机器 ID 自定义更大的结构。

主手持矩阵，潜行右键专用驱动器插入；主手空手潜行右键取出。副手可持物品。创造模式插入同样移走这一枚矩阵，避免复制其中的内容。驱动器已有矩阵时不会覆盖。A／B／C 对应 16M／64M／256M，各有物品、流体、气体三种；S4 支持 A，S6 支持 A／B，S9 支持全部。不支持的矩阵可放入保管，但不激活。

接入 AE2 时，将 ME 通道接到有空闲频道、有电的 ME 网络。可用 AE 能源接收器向网络供电；每台 ES 的通道占一个频道，矩阵共享这一通道。待 ME 网络启动完成后，可从连接该网络的终端查看、存入和取出矩阵里的物品／流体。仅物品终端不能代替流体操作入口，应使用 AE 支持流体的终端操作。

主机基础耗能为 64 AE/t，另加当前受支持且可读取的矩阵耗能：A 为 15.625 AE/t，B 为 62.5 AE/t，C 为 250 AE/t。一次物品／流体转移的额外耗能由 AE 终端等操作入口负责；ES 通道向网格申报待机耗能，不重复扣除这笔待机电力。

内部能源单元 L4／L6／L9 分别储存 1,000 万／1 亿／10 亿 AE。把网络接到 AE 能源接收器即可充电，储能可在外部供电断开后继续支持网络；没有单独的 FE 插口。主机汇总所有匹配到的能源单元，充电先用存量少的，放电先用存量多的。拆下保留电量，放回恢复；物品提示显示存量／容量。世界电量材质每五 tick 更新，带电物品也按 0／5%／50%／70%／90% 五档显示正面电量；物品模型不会改变保存的能量。与源版相同，能源单元本身不受主机档位限制。

配置矩阵时先从驱动器取出，放入 AE2 **元件工作台**。工作台提供 63 格虚拟过滤项和两个升级槽；“分区”按已有内容生成过滤项，“清除”清过滤项，都不会清空实际库存。分区格数不是矩阵可存类型上限。默认白名单，一张反相卡切为黑名单；空列表不限制存入。物品矩阵另支持一张模糊卡及耐久分组设置，流体矩阵保持精确匹配，不接受模糊卡；速度／销毁／均分卡不支持。改完取出再插回 ES 驱动器生效。过滤只限制存入，已有内容始终能按精确物品／流体取出；模糊规则不合并库存中的不同 NBT。物品提示显示容量与分区信息。

每个结构最多一个 ME 通道；多个通道不会分别把同一枚矩阵接入不同网络。断电、频道不足、网络启动期间、红石停止、结构失效或部件卸载时，ES 不提供网络库存。恢复后保留矩阵内容并重新挂载。换矩阵后，旧库存引用不能跟随访问新矩阵。

没有 AE2 时方块与矩阵仍保留，可物理插拔和保存，存储后端不开启；矩阵不能装进普通 ME 驱动器或 ME 箱子。内部能源单元仍保存电量，但没有 ME 网络接口可用；主机统计界面可查看结构与能源数据；驱动器支持漏斗／管道从各面插拔整枚矩阵，只有一格、容量一枚，不是矩阵内部物品槽。源版输入／输出总线为空占位，优先级固定 0，未增加编辑入口。当前只是开发阶段的 ME 通道流程，不建议直接替换真实整合包的存储系统。

模型和纹理来自 NovaEngineering Core（GPLv3），署名及固定源码版本见项目根目录 `THIRD-PARTY-NOTICES.md`。阶段进度见 `docs/NECO_GUIDE_ZH.md`。

开发版外观：驱动器显示矩阵类型／等级，上灯绿／橙／红表示有空间／类型已满／容量已满，下灯在实际存取后蓝色闪动约 40 tick。源版 ES 成型模型会占用并隐藏控制器周围固定的 11 个邻格；最小演示只用于部件流程，设计正式结构时应为该模型预留空间。隐藏只影响显示，不取消碰撞或结构要求。

## 气体矩阵（开发版）

安装 AE2、Mekanism 和 Applied Mekanistics 后，可用 `modularmachinery:estorage_cell_gas_16m`、`estorage_cell_gas_64m`、`estorage_cell_gas_256m`。将气体矩阵插入相应等级的 ES 主机驱动器，接上前述 ME 通道，通过 Applied Mekanistics 支持的气体终端／总线存取。不能用流体操作入口代替气体入口。

每枚气体矩阵最多 25 种气体，容量、类型开销、矩阵倍率和耗能沿用同档 ES 矩阵规格。只存气体，不接受灌注、颜料或浆液。工作台提供 63 个气体过滤格和两格升级，支持反相卡，不支持模糊卡。取出、改分区、重新插入后生效；过滤不阻止取出已有内容。主机界面的气体类型与流体类型分开统计，右侧矩阵列使用源版气体图案。

没有 Applied Mekanistics 时，气体矩阵仍保留注册 ID，可物理取放、保存和掉落；不开启气体库存、不解析未知化学品 NBT，也不收取该矩阵待机耗能。物品提示会说明缺少依赖。恢复依赖后可重新读取有效的原数据。缺少依赖时不提供工作台编辑入口；已经损坏或未知资源的数据保留原样并拒绝挂载，不会按空矩阵清除。
